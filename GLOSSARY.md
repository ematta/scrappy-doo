# QA Execution

The language used to describe an agent carrying out quality assurance on an application.

## Language

**Test goal**:
A quality outcome that a QA engineer asks the agent to verify in an application.

**Test execution**:
An attempt to verify a test goal against an application, including the resulting findings and evidence.

**Application knowledge**:
Durable information about a particular application, such as its terminology, navigation, and known workflows.

**Knowledge proposal**:
An observation proposed for inclusion in application knowledge and awaiting a QA engineer's review.

**Approved knowledge**:
Application knowledge a QA engineer has accepted for use in future test executions.

**Inconclusive result**:
A test result in which the available evidence does not establish whether the test goal passed or failed.

**Interrupted execution**:
A test execution that stopped before completing, leaving any recorded findings and evidence available for review.
